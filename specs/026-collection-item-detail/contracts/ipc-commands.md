# IPC Contracts: Collection Item Detail View

**Branch**: `026-collection-item-detail` | **Date**: 2026-02-22

All contracts below are **existing** Tauri IPC commands. No new commands are introduced.
All types are generated by `specta` and live in `src/lib/bindings.ts`.

---

## Read Operations Used by This Feature

### `get_collection`

```
Command:   get_collection
TS method: commands.getCollection()
Returns:   Result<CollectionView, CommandError>
When used: CollectionStore.fetch() — on startup and on direct page refresh
Cache:     Yes — skipped if CollectionStore.items.length > 0
SLO:       < 200ms (read query, constitution requirement)
```

`CollectionView` payload (fields relevant to this feature):

```typescript
{
  id: CollectionId;
  items: CollectionItemView[];   // ← full list, each with purchaseInfo + rollingStocks
  summary: CollectionSummary;
  totalValue: MonetaryAmount | null;
}
```

### `get_railway_model_by_id`

```
Command:   get_railway_model_by_id
TS method: commands.getRailwayModelById(railwayModelId)
Input:     RailwayModelId (string URN)
Returns:   Result<RailwayModelView | null, CommandError>
When used: Detail page on mount — parallel with getRailwayModelImage
SLO:       < 200ms
```

### `get_railway_model_image`

```
Command:   get_railway_model_image
TS method: commands.getRailwayModelImage(railwayModelId)
Input:     RailwayModelId (string URN)
Returns:   Result<RailwayModelImageResponse, CommandError>
When used: Detail page on mount — parallel with getRailwayModelById
SLO:       < 200ms (may be longer if image is large; acceptable for non-critical UI)
```

`RailwayModelImageResponse`:

```typescript
{
  imagePath: string | null;
  placeholderHtml: string | null;
  hasImage: boolean;
}
```

### `get_seller_by_id`

```
Command:   get_seller_by_id
TS method: commands.getSellerById(id)
Input:     SellerId (string)
Returns:   Result<SellerView | null, CommandError>
When used: Detail page on mount — only if PurchasedInfo.seller != null
SLO:       < 200ms
```

`SellerView` fields consumed:

```typescript
{
  id: SellerId;
  name: string; // displayed as plain text or anchor text
  websiteUrl: string | null; // if present, name becomes <a href={websiteUrl}>
}
```

---

## Parallel Loading Strategy

On detail page mount, after `collectionItem` is resolved from the store:

```
Promise.all([
  getRailwayModelById(railwayModelId),
  getRailwayModelImage(railwayModelId),
  sellerId ? getSellerById(sellerId) : Promise.resolve(null),
])
```

This keeps the total additional round-trip count to **one concurrent batch** rather than
three sequential calls.
