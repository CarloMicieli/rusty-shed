# API Contracts: Track Inventory Feature

**Feature**: 005-track-inventory  
**Created**: 2026-01-30

## Overview

All frontend-backend communication uses Tauri IPC via `invoke`. Types are generated by specta/tauri-specta into `src/lib/bindings.ts`.

## Commands (Write Operations)

Commands follow ADR-8 conventions: `Args` for transport, `Input` for use-case.

### create_track_inventory

Creates a new track inventory.

**Request** (`NewTrackInventoryArgs`):

```typescript
{
  name: string;           // Required, 1-100 chars
  description?: string;   // Optional
}
```

**Response**: `TrackInventoryId` (string)

**Errors**:

- `ValidationError`: Invalid name
- `DatabaseError`: Persistence failure

**Example**:

```typescript
const result = await commands.createTrackInventory({
  name: 'Main Layout',
  description: 'HO scale track for the main layout'
});
if (result.status === 'ok') {
  console.log('Created:', result.data); // TrackInventoryId
}
```

### rename_track_inventory

Renames an existing track inventory.

**Request** (`RenameTrackInventoryArgs`):

```typescript
{
  id: string; // TrackInventoryId
  name: string; // New name, 1-100 chars
}
```

**Response**: `null` (void)

**Errors**:

- `NotFoundError`: Inventory not found
- `ValidationError`: Invalid name

---

### delete_track_inventory

Deletes a track inventory and all associated purchases (CASCADE).

**Request** (`DeleteTrackInventoryArgs`):

```typescript
{
  id: string; // TrackInventoryId
}
```

**Response**: `null` (void)

**Errors**:

- `NotFoundError`: Inventory not found

**Side Effects**:

- Deletes all associated track purchases (CASCADE via database constraint)
- Deletes all associated inventory items

---

### add_track_purchase

Adds a purchase to an inventory, updating stock quantities.

**Request** (`AddTrackPurchaseArgs`):

```typescript
{
  inventory_id: string;   // TrackInventoryId
  items: Array<{          // One or more purchase items (FR-009)
    track_id: string;     // TrackId of product purchased
    quantity: number;     // Positive integer
  }>;
  price_amount: number;   // Total price in smallest currency unit (cents)
  price_currency: string; // ISO currency code (e.g., "EUR")
  seller_id?: string;     // Optional SellerId
  purchase_date: string;  // ISO date string (YYYY-MM-DD)
}
```

**Response**: `TrackPurchaseId` (string)

**Errors**:

- `NotFoundError`: Inventory or track product not found
- `ValidationError`: Invalid quantity, price, or empty items array

**Side Effects**:

- Increments inventory quantity for each track type in items array

---

### set_track_item_quantity

**Request** (`SetTrackItemQuantityArgs`):

```typescript
{
  inventory_id: string; // TrackInventoryId

  quantity: number; // Non-negative integer (0 removes item)
}
```

**Response**: `null` (void)

**Errors**:

- `NotFoundError`: Inventory not found
- `ValidationError`: Negative quantity

## Queries (Read Operations)

New query handlers to be implemented. Return View structs from application layer.

### get_track_inventories

Lists all track inventories with summary information.

**Request**: None

**Response** (`TrackInventoryListItem[]`):

```typescript
[
  {
    id: string;             // TrackInventoryId
    name: string;
    description: string | null;
    total_items: number;    // Count of distinct track types
    total_quantity: number; // Sum of all quantities
  }
]
```

**Example**:

```typescript
const result = await commands.getTrackInventories();
if (result.status === 'ok') {
  result.data.forEach((inv) => {
    console.log(`${inv.name}: ${inv.total_quantity} pieces`);
  });
}
```

### get_track_inventory

Gets a single track inventory with full details.

**Request**:

```typescript
{
  id: string; // TrackInventoryId
}
```

**Response** (`TrackInventoryView`):

```typescript
{
  id: string;
  name: string;
  description: string | null;
  items: TrackInventoryItemView[];
  purchases: TrackPurchaseView[];
}

// Where:
interface TrackInventoryItemView {
  track_id: string;
  track_product: TrackProductView;
  quantity: number;
  required: number;
}

interface TrackProductView {
  track_id: string;
  manufacturer_name: string;
  product_code: string;
  description: string;
  track_type: "STRAIGHT" | "CURVE" | "TURNOUT" | "FLEX_TRACK";
  track_code: "CODE_70" | "CODE_75" | "CODE_83" | "CODE_100";
  with_roadbed: boolean;
  length: Length | null;
  radius: Length | null;
}

interface TrackPurchaseView {
  id: string;
  track_product: TrackProductView;
  quantity: number;
  price: MonetaryAmount;
  seller_name: string | null;
  purchase_date: string;  // YYYY-MM-DD
}
```

**Errors**:

- `NotFoundError`: Inventory not found

## Frontend Service Interface

The `TrackInventoryService` wraps these commands:

```typescript
class TrackInventoryService {
  // Queries
  async fetchInventories(): Promise<void>;
  async fetchInventory(id: string): Promise<void>;
  async fetchProducts(): Promise<void>;

  // Commands
  async createInventory(input: NewTrackInventoryArgs): Promise<string | null>;
  async renameInventory(input: RenameTrackInventoryArgs): Promise<boolean>;
  async addPurchase(input: AddTrackPurchaseArgs): Promise<string | null>;
  async setItemQuantity(input: SetTrackItemQuantityArgs): Promise<boolean>;

  // State
  get inventories(): TrackInventoryListItem[];
  get selectedInventory(): TrackInventoryView | null;
  get products(): TrackProductView[];
  get isLoading(): boolean;
}
```

## Invocation Patterns

Use the `safeInvoke` wrapper from `$lib/shared/services/TauriAdapter`:

```typescript
import { safeInvoke } from '$lib/shared/services/TauriAdapter';

// Query
const result = await safeInvoke<TrackInventoryView>('get_track_inventory', { id });
if (result.ok) {
  this.#selectedInventory = result.data;
} else {
  toaster.error({ title: getErrorMessage(result.error) });
}

// Command
const result = await safeInvoke<TrackInventoryId>('create_track_inventory', { input });
if (result.ok) {
  await this.fetchInventories(); // Refresh list
  return result.data;
}
return null;
```
