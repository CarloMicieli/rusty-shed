# API Contract: Upload Model Image

**Command**: `upload_model_image`
**Domain**: `media`
**Date**: 2026-02-11

## Overview

Tauri IPC command that handles image upload for railway models. Validates the image file (type, size, dimensions), saves it to the media storage directory, and returns the relative path for persistence.

## Business Rules (Backend Validation)

### File Type Validation

- **Method**: Magic number detection (not file extension)
- **Allowed MIME Types**: `image/jpeg`, `image/png`, `image/webp`, `image/gif`
- **Rationale**: Prevents spoofing via extension renaming

### File Size Validation

- **Max Size**: 10 MB (10,485,760 bytes)
- **Min Size**: 1 byte (non-empty)
- **Rationale**: Prevents memory issues and ensures valid file

### Dimension Validation

- **Max Dimensions**: 4096 x 4096 pixels
- **Min Dimensions**: 100 x 100 pixels
- **Rationale**: Max prevents memory exhaustion, min ensures usability

### Storage Rules

- **Location**: `{app_data_dir}/media/images/railway_models/{railway_model_id}/{timestamp}_{original_filename}`
- **Filename**: Preserve original filename with timestamp prefix for uniqueness
- **Overwrite**: New upload replaces old image (old file deleted)

## Use Case Flow

### Happy Path

1. **Frontend** calls Tauri file dialog → user selects image
2. **Frontend** invokes `upload_model_image` with `railway_model_id` and `file_path`
3. **Backend** validates `UploadModelImageArgs` (args.validate())
4. **Backend** checks if `railway_model_id` exists in database
5. **Backend** creates `ModelImage::validate(file_path)` → validates type, size, dimensions
6. **Backend** copies file to media storage directory
7. **Backend** returns `UploadModelImageResult` with relative path
8. **Frontend** receives result → calls `onImageUploaded(result.image_path)`
9. **Parent Page** updates model data → component re-renders with new image

### Error Path 1: Invalid File Type

1-3. Same as happy path 4. **Backend** `ModelImage::validate()` detects MIME type is `application/pdf` 5. **Backend** returns `Err(ImageValidationError::UnsupportedFormat("application/pdf"))` 6. **Frontend** catches error → displays toast: "Invalid image format. Please upload a JPEG, PNG, WebP, or GIF file."

### Error Path 2: File Too Large

1-3. Same as happy path 4. **Backend** `ModelImage::validate()` checks file size is 15 MB 5. **Backend** returns `Err(ImageValidationError::FileTooLarge { size: 15728640, max: 10485760 })` 6. **Frontend** catches error → displays toast: "Image file is too large. Maximum size is 10 MB."

### Error Path 3: Model Not Found

1-3. Same as happy path 4. **Backend** queries database for `railway_model_id` → not found 5. **Backend** returns `Err(CommandError::ModelNotFound(railway_model_id))` 6. **Frontend** catches error → displays toast: "Railway model not found."

## Security Considerations

### Path Traversal Prevention

- **Risk**: User provides malicious `file_path` like `../../etc/passwd`
- **Mitigation**: Backend canonicalizes path and verifies it's within allowed directories

```rust
let file_path = Path::new(&args.file_path).canonicalize()?;
if !file_path.starts_with(ALLOWED_TEMP_DIR) {
    return Err(CommandError::Validation("Invalid file path".into()));
}
```

### MIME Type Spoofing Prevention

- **Risk**: User renames `malware.exe` to `image.jpg`
- **Mitigation**: Detect MIME type via magic numbers (file header), not extension

```rust
let mime_type = detect_mime_type(&file_path)?; // Reads file header bytes
```

### Resource Exhaustion Prevention

- **Risk**: User uploads 100 GB image or 50000x50000 pixel image
- **Mitigation**: Enforce max file size (10 MB) and max dimensions (4096x4096)
