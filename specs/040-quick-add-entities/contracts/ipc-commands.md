# IPC Contracts: On-the-Fly Entity Quick-Add (040)

**Date**: 2026-05-15  
**Transport**: Tauri IPC — `invoke()` via specta-generated `commands` object  
**Convention**: Follows ADR-8 — `Args` for write payloads; returns `Result<T, CommandError>` on writes

---

### 2. `create_manufacturer` ❌ Missing — to be delivered by 041

**Proposed module**: `src-tauri/src/catalog/interface/manufacturers.rs`

```rust
#[tauri::command]
#[specta::specta]
pub async fn create_manufacturer(
    state: tauri::State<'_, AppState>,
    args: CreateManufacturerArgs,
) -> Result<Manufacturer, CommandError>

/// Transport DTO — must derive specta::Type + garde::Validate
#[derive(Debug, Clone, Serialize, Deserialize, specta::Type, garde::Validate)]
#[serde(rename_all = "camelCase")]
pub struct CreateManufacturerArgs {
    /// Required. Trimmed. Case-insensitively unique.
    #[garde(length(min = 1, max = 200))]
    pub name: String,
    /// Optional. Valid URL.
    pub website_url: Option<String>,
    /// Optional. ISO 3166-1 alpha-2.
    #[garde(length(min = 2, max = 2))]
    pub country_code: Option<String>,
}
```

**TypeScript (to be generated by 041)**:
```typescript
type CreateManufacturerArgs = {
  name: string;
  websiteUrl: string | null;
  countryCode: string | null;
};

commands.createManufacturer(args: CreateManufacturerArgs): Promise<Result<Manufacturer, CommandError>>
```

**Return value**: Full `Manufacturer` object (including the generated `id`). The frontend pushes this directly into the local state array — no re-fetch required.

**Error cases**:
- `CommandError::Conflict` — name already exists (case-insensitive)
- `CommandError::ValidationError` — field validation failed
- `CommandError::DatabaseError` — unexpected persistence failure

### 4. `create_seller` ✅ Exists

**Module**: `src-tauri/src/sellers/interface/command_handlers.rs`

```rust
#[tauri::command]
#[specta::specta]
pub async fn create_seller(
    state: tauri::State<'_, AppState>,
    payload: CreateSellerPayload,
) -> Result<Seller, CommandError>
```

**TypeScript (generated)**:
```typescript
type CreateSellerPayload = {
  name: string;
  sellerType: SellerType;         // "SHOP" | "PRIVATE" | "MARKETPLACE" | "DISTRIBUTOR"
  email: string | null;
  phone: string | null;
  websiteUrl: string | null;
  streetAddress: string | null;
  // ... other address fields
  countryCode: string | null;
};

commands.createSeller(payload: CreateSellerPayload): Promise<Result<Seller, CommandError>>
```

**Usage in 040 (Quick-Add mode)**:
- `name`: user input (trimmed)
- `sellerType`: fixed default `"SHOP"` (not exposed in Quick-Add form)
- `websiteUrl` / `countryCode`: from optional form fields
- All other fields: `null`

**Buyer variant**: Identical call. `sellerType` defaults to `"SHOP"`. The drawer title changes to "Add Buyer" but the underlying command and payload structure are the same.

**Return value**: Full `Seller` object. Frontend casts to `SellerView` shape (all fields present) and pushes into local `sellers` state array.

## Zod Schema (frontend validation, new file)

**File**: `src/lib/schemas/quick-add-form.ts`

```typescript
import { z } from 'zod';
import * as m from '$paraglide/messages';

export const quickAddFormSchema = z.object({
  name: z
    .string()
    .trim()
    .min(1, () => m.quick_add_name_required()),
  websiteUrl: z
    .string()
    .url()
    .optional()
    .or(z.literal('')),
  countryCode: z
    .string()
    .length(2)
    .optional()
    .or(z.literal('')),
});

export type QuickAddFormValues = z.infer<typeof quickAddFormSchema>;
```
