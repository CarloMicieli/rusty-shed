## Use Case Logic (`UpdateRailwayModelClassification::execute`)

1. Load `RailwayModel` by `railway_model_id` (return `DomainError::NotFound` if absent)
2. If `scale.is_some()` → `model.update_scale(scale.unwrap())` — emits `RailwayModelUpdated { changed: {"scale": "H0"} }`
3. If `epoch.is_some()` → `model.update_epoch(epoch.unwrap())` — emits `RailwayModelUpdated { changed: {"epoch": "IV"} }`
4. `repository.save(&mut model).await?` — drains both events → SQL `UPDATE railway_models SET scale = ?, epoch = ?` (or individual updates per event)

## New Domain Methods on RailwayModel

```rust
/// Update the Scale classification and emit a RailwayModelUpdated event.
pub fn update_scale(&mut self, scale: Scale) {
    self.scale = scale;
    self.push_event(RailwayModelEvent::RailwayModelUpdated {
        event_id: Uuid::new_v4(),
        railway_model_id: self.id.clone(),
        timestamp: Utc::now().naive_utc(),
        changed: serde_json::json!({ "scale": self.scale }),
    });
}

/// Update the Epoch classification and emit a RailwayModelUpdated event.
pub fn update_epoch(&mut self, epoch: Epoch) {
    self.epoch = epoch;
    self.push_event(RailwayModelEvent::RailwayModelUpdated {
        event_id: Uuid::new_v4(),
        railway_model_id: self.id.clone(),
        timestamp: Utc::now().naive_utc(),
        changed: serde_json::json!({ "epoch": self.epoch }),
    });
}
```

## Error Cases

| Scenario                                     | Error                                                                     |
| -------------------------------------------- | ------------------------------------------------------------------------- |
| `railway_model_id` not found                 | `CommandError::NotFound`                                                  |
| Invalid `Scale` enum value (deserialization) | `CommandError::ValidationError`                                           |
| Invalid `Epoch` enum value (deserialization) | `CommandError::ValidationError`                                           |
| Both `scale` and `epoch` are null (no-op)    | `CommandError::ValidationError { args: ["at least one field required"] }` |
| Database failure                             | `CommandError::DatabaseError`                                             |
