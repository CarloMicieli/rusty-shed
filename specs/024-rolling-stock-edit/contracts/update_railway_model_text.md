# Contract: update_railway_model_text

**Command**: `update_railway_model_text`
**Trigger**: Blur-to-save on description or details in-place edit field (FR-001, FR-002, FR-003)
**Layer path**: `Args → UpdateRailwayModelTextInput → UpdateRailwayModelText::execute → RailwayModelRepository::save`

---

## Use Case Logic (`UpdateRailwayModelText::execute`)

1. Load `RailwayModel` by `railway_model_id` (return `DomainError::NotFound` if absent)
2. Match on `field`:
   - `Description` → `model.update_description(value)` (domain validates non-empty)
   - `Details` → `model.update_details(if value.is_empty() { None } else { Some(value) })`
3. `repository.save(&mut model).await?` — drains `RailwayModelUpdated` event → SQL `UPDATE railway_models SET description = ? / details = ?`
