## Use Case Logic (`UpdateRollingStockRailwayCompany::execute`)

1. Verify `railway_company_id` exists in `railway_companies` table (return `DomainError::NotFound` if not)
2. Load `RailwayModel` by `railway_model_id` (return `DomainError::NotFound` if absent)
3. Locate rolling stock with `rolling_stock_id` inside the aggregate (return `DomainError::NotFound` if absent)
4. Call `model.update_rolling_stock_railway_company(rolling_stock_id, railway_company_id)`
   - Mutates the matching `RollingStock` variant's `railway_id` field
   - Emits `RollingStockUpdated { changed: {"railway_company_id": "..."} }`
5. `repository.save(&mut model).await?` → `UPDATE rolling_stocks SET railway_company_id = ? WHERE id = ?`

## New Domain Method on RailwayModel

```rust
pub fn update_rolling_stock_railway_company(
    &mut self,
    rolling_stock_id: &RollingStockId,
    company_id: RailwayCompanyId,
) -> Result<(), DomainError> {
    let rs = self.rolling_stocks.iter_mut()
        .find(|rs| rs.id_as_ref() == rolling_stock_id)
        .ok_or_else(|| DomainError::NotFound { ... })?;

    rs.set_railway_company(company_id.clone());

    self.push_event(RailwayModelEvent::RollingStockUpdated {
        event_id: Uuid::new_v4(),
        railway_model_id: self.id.clone(),
        rolling_stock_id: rolling_stock_id.clone(),
        timestamp: Utc::now().naive_utc(),
        changed: serde_json::json!({ "railway_company_id": company_id }),
    });
    Ok(())
}
```
